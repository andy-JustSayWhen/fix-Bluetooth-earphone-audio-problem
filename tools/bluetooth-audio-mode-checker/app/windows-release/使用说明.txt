蓝牙音频设备模式检查器 {{VERSION}}

使用方法
========

1. 请先把整个压缩包完整解压到一个普通文件夹。
2. 双击根目录的“一键运行.cmd”。
3. 浏览器会自动打开本机检测页面。
4. 使用期间请保持黑色启动窗口打开；关闭窗口即可停止应用。

本版本已经内置运行环境，不需要安装 Node.js，也不需要联网安装依赖。

常见问题
========

一、浏览器没有自动打开

在浏览器地址栏输入：
http://127.0.0.1:4173/

二、提示端口 4173 被占用

工具会自动寻找一个空闲端口并继续启动，不需要关闭占用端口的其他程序。
请以启动窗口最后显示的地址为准。

三、Windows 显示安全提示

本工具是免安装脚本，不写入注册表、不创建开机启动项，也不安装系统服务。
请确认压缩包来自项目官方 GitHub Release 页面。

四、在哪里找运行日志

日志位于解压目录的 logs 文件夹。遇到问题时，请连同启动窗口中的错误信息一起反馈。
