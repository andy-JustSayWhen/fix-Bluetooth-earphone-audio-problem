快速检查蓝牙音频模式 一键修复蓝牙扬声器声音异常

绝大多数的蓝牙耳机等蓝牙音频设备都不支持LE Audio。这意味着，一旦电脑的某个App调用了该设备的麦克风，期间，该设备就会进入HFP模式。在该模式下，如果扬声器在播放音频，那么听感会变得非常闷，音质非常差，有时还会伴随回音。本工具可以快速帮你检测电脑上的某个蓝牙音频设备是否处于HFP模式，如果处于，则可以通过工具的“一键修复”按钮，尝试自动修复。
