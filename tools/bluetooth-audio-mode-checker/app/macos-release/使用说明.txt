蓝牙音频设备模式检查器 {{VERSION}}（macOS 通用版）

使用方法

1. 必须先完整解压本压缩包，不能直接在压缩包预览中运行。
2. 双击根目录的“一键运行.command”。
3. 保持弹出的终端窗口开启，浏览器会自动打开工具页面。
4. 使用结束后，关闭终端窗口即可停止工具。

运行环境

- 已内置 Node.js 和声音组件，不需要另行安装 Node.js、苹果命令行编译工具或其他开发依赖。
- 同时支持苹果芯片 Mac 和英特尔芯片 Mac，启动器会自动选择对应运行环境。

常见问题

- 如果系统首次阻止打开：在访达中按住 Control 键点按“一键运行.command”，选择“打开”，再确认一次。
- 如果默认端口已经被占用：工具会自动寻找新的空闲端口，无需关闭其他软件。
- 如果浏览器没有自动打开：查看终端窗口最后显示的 http://127.0.0.1:端口 地址并手动打开。
- 如果提示运行环境不完整：删除当前目录，重新下载压缩包并完整解压。

隐私说明

网页只监听这台电脑的本机地址。设备检测结果、操作和日志不会通过本工具上传到互联网。
