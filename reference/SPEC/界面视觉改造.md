# 蓝牙音频模式检查器界面视觉改造

## 定位

本文规定蓝牙音频模式检查器网页的视觉语言、页面层级、响应式行为、素材来源和验收边界。项目架构以项目根目录 [`Architecture.md`](../../Architecture.md) 为唯一原文。

本次改造只调整页面结构与视觉表达，不改变设备模式判定、声音路由切换、麦克风占用、扬声器占用、一键修复及详细日志的业务规则。

## 用户目标

用户打开页面后，应先看懂工具用途和当前整体状态，再完成以下核心操作：

1. 刷新并查看当前蓝牙音频设备。
2. 查看或切换系统默认输入、输出设备。
3. 展开设备，核对模式、协商格式、占用程序和修复状态。
4. 在页面窄屏状态下仍能完成相同操作，且不出现横向滚动或信息遮挡。

## 视觉来源与转译规则

参考视觉为 `https://www.uupm.cc/demo/restaurant-food` 的通用设计语言：奶油色纸张背景、深棕色边框与投影、橙红强调色、衬线展示标题、清晰分区和宽松留白。

不得复制参考站的餐厅名称、菜单、人物故事、联系方式或食物照片。页面应将相同视觉语言转译为蓝牙声音工具：

- 首屏标题表达“识别模式、恢复高音质”的用户价值。
- 参考网页只用于提取适合本工具的颜色、字体层级、边框和留白，不得为了复刻构图而加入没有功能价值的内容。
- 首屏优先展示工具用途、操作按钮和真实检测状态；没有帮助用户理解或操作的装饰图片、标签和说明框不得占用首屏空间。
- 页面正文继续使用现有中文事实与固定文案，不将内部规划或参考站文案暴露给用户。
- 设备详情属于高密度诊断信息，可以比参考站卡片更紧凑，但颜色、边框、阴影与标题层级必须保持统一。

## 设计系统

- 背景：暖奶油色；分区可使用稍深的纸张色或深棕色。
- 文字：深咖啡色；次要说明使用中性棕灰，保证正文对比度不低于 `4.5:1`。
- 强调色：橙红色，用于主要操作、状态重点和标题强调；不得只依靠颜色表达设备状态。
- 标题：中文衬线字体优先，粗细与字号形成明确层级；正文使用清晰的中文无衬线字体。
- 卡片：细深棕边框配合右下错位硬投影；设备卡片、按钮、选择框共享同一边框语言。
- 动效：只使用透明度和位移动效，时长控制在 `150` 至 `300` 毫秒，并尊重系统减少动态效果设置。

## 页面结构

1. 顶部导航：品牌名称和两个直达页面分区的锚点；不额外放置重复操作按钮。
2. 首屏：集中展示工具用途、当前状态摘要和主要操作，不放置与检测任务无关的装饰图片区。
3. 声音路由：保留输入、输出选择框和当前写入结果提示。
4. 设备工作台：保留设备数量、更新时间、一键修复入口、其他输入活动和设备列表。
5. 页面在设备工作台结束，不设置仅重复品牌或返回顶部的页脚。

## 素材与图标

- 只有能解释功能、状态或操作的图片才能进入页面；纯装饰位图即使质量合格，也不得为了填满版面而展示。
- 界面图标优先使用同一开源图标库的本地文件；不得用表情符号、文字字符、网页元素绘图或临时占位图代替。
- 页面使用图片时必须提供中文替代文字，并根据版面使用合适裁切；不得拉伸。

## 交互与响应式

- “刷新设备”仍使用现有 `refresh-button`，点击后立即恢复，不在页面增加固定冷却倒计时。
- 声音路由选择框、设备展开、一键修复和解除占用继续复用现有控制器与接口。
- 电脑端和窄屏端的首屏都以单一任务流呈现，先说明用途，再展示操作和实时状态。
- `390 × 844` 像素视口不得出现横向滚动；所有触控目标至少 `44 × 44` 像素。
- 键盘焦点必须清晰可见，设备展开按钮继续保留正确的展开状态属性。

## 页面文案

- 页面名称统一使用“蓝牙音频设备模式检查器”，不得使用“声境”等无法直接说明用途的自造词。
- 标题、导航、按钮和分区名称必须直接说明“检查什么”或“点击后会发生什么”，不得为了模仿参考站而使用空泛的营销式短语。
- 面向普通用户的摘要不得只显示协议缩写；例如需要把 HFP 说明为“低音质通话模式”。设备详情中的技术字段可以保留协议名称，但必须同时给出中文解释。
- 声音设备选择区统一使用“扬声器”和“麦克风”，不在主界面标题中使用“路由”“端点”“工作台”等需要额外理解的术语。
- 动态检测结果、程序名称和系统返回的错误属于事实信息，不得为了润色而改变原意。

## 性能与验收

1. 首屏不得加载与核心任务无关的大幅位图，避免增加下载与解码开销。
2. 视觉改造不得增加完整设备扫描、声音端点读取或后台轮询次数。
3. 自动测试全部通过，页面脚本没有控制台错误。
4. 宽屏与 `390 × 844` 像素页面均完成真实浏览器截图检查。
5. 刷新设备接口和声音路由切换速度必须重新核验；页面视觉完成不能替代真实功能与速度验收。
